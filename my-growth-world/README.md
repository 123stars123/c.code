# MY GROWTH WORLD

简体中文、本地优先的个人成长档案 MVP。独立项目，与桌宠无运行依赖。

## 启动

需要 Node.js 22+（当前验证 24.22.1）。

```sh
cd /workspace/c.code/my-growth-world
npm ci --cache /tmp/npm-cache
npm run dev -- --port 5173
```

开发服务器监听 0.0.0.0:5173。请使用云环境的端口访问能力打开，或在本机运行后访问浏览器中的对应端口。不要把开发服务器暴露到公开互联网。

```sh
npm run build
npm test
```

测试默认使用 `/usr/bin/chromium`；其他电脑设置 `CHROMIUM_PATH` 为本机 Chromium 可执行文件路径。运行测试前启动开发服务器。浏览器自动化使用隔离数据，不更改真实用户档案。

## 功能

- 首页、原创 SVG 六区域地图（缩放、滚动浏览）、可点击连接技能图。
- 31 条用户提供经历预置为待确认节点，无虚构成就或日期。创建/编辑/删除节点、五种手动状态、前置连接、关联成就。
- 收藏成就卡片，完整经历字段、草稿状态、编辑/详情/删除确认。
- 经历与日常行动 CRUD；时间线按路线筛选，支持准确日期与文字阶段；记录节点状态变化。
- IndexedDB 本地持久化。保存成功后才更新界面，失败显示错误。
- 完整 JSON 导出，合并恢复预览、确认，恢复前自动备份并下载。相同 ID 保留本机版本；文件内部重复也去重。
- 支持 `my-growth-world.activity-import` schemaVersion 1 事件导入。按 eventId 去重，不生成成就、不自动完成技能。

## 数据约定

IndexedDB 数据库 `my-growth-world`，版本 1，`archive` 对象仓库。`current` 保存完整档案，`before-restore` 保留最近一次恢复前档案。完整导出包含路线、节点、成就、行动、节点状态变化与设置。合并保留现有路线与本机设置；不覆盖同 ID 记录。每条核心实体包含 id、createdAt、updatedAt。成就预留 attachments，节点引用 achievementIds 与 parentId。

数据属于当前浏览器和站点 origin：协议、主机、端口任一变化都会形成另一份存储。关闭或刷新应用保留数据；清除浏览器站点数据、隐私模式关闭或更换浏览器可能丢失。建议定期导出到浏览器外。没有登录、自动上传或在线图片依赖。不要把 IndexedDB 当作唯一长期备份。

## MVP 范围与限制

没有附件上传、云同步、账户、AI 调用、桌宠实时通信、移动端专项适配和桌面打包。地图支持缩放与滚动，不支持按住画布拖拽。模态表单兼作详情页。文字阶段不能准确排序，因此没有日期的记录按最近更新时间展示。节点日志保留状态变化，非完整字段审计。初始经历须由用户手动核实，创建正式成就需用户显式创建并确认状态。

下一步建议：完善导入冲突逐条处理、数据库升级迁移测试、附件存储与可访问性；再考虑桌宠离线事件同步。

## 验证结果

已运行 `npm run build`：TypeScript 检查及生产构建通过。
已运行 `npm test`：4 项 Chromium 浏览器测试通过，覆盖：

1. 初始草稿、创建节点、成就增删改、刷新持久化、六区域导航及备份预览。
2. 非法版本文件被拒绝，已有档案不被改写。
3. 手动确认节点、状态变化时间线、关闭页面再打开及节点删除。
4. 成就关联、删除后从备份真正恢复、重复事件导入去重。

GitHub 仅保存代码和测试；浏览器中的真实成长档案不会自动提交。首次打开新浏览器仍需自行导入个人备份。
